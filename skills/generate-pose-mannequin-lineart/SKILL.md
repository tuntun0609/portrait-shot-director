# 生成人物白模动作线稿

## 目标

把人物照片或姿势简报转换成可供画师继续设计角色的动作底稿。优先保证姿势、透视、手部结构和遮挡关系，不保留人物身份、妆容、服饰或场景信息。

先读取并遵循当前环境中的 `imagegen` 技能。本技能只补充白模动作稿的专用流程与质量标准。

## 默认成品标准

- 只保留人物的头部、颈部、躯干、四肢、手掌和可见手指。
- 使用纯黑、平滑、连续且粗细稳定的轮廓线，背景与人物内部均为纯白；不得用浅灰抗锯齿观感冒充灰色线稿、阴影或纸张纹理。
- 保持原图画幅比例、裁切、人物位置、头部角度、躯干倾斜、肢体长度、透视缩短和遮挡顺序。
- 保留每根可见手指的分界、指蹼转折、关节弯曲、掌缘和必要的重叠线；删除指甲与无助于读姿势的皮肤纹路。
- 将头部处理为无发型、无耳朵、无五官、无任何内部辅助线的光滑白模；将躯干处理为无衣服特征、无明确性征的基础体块。
- 删除背景、道具、文字、饰品、颜色、灰度、阴影、排线、材质、服装缝线与褶皱。
- 不把自然的不对称姿势改成镜像、正面或标准对称姿势。

## 风格预设

先判断用户要哪一种，不要混合比例规则：

- **真实比例白模（默认）**：忠实保留姿势参考中的人体比例、体块和透视，只移除身份与表面特征。
- **修长极简人台**：当用户要求“像示例”“修长”“时装人台”“极简动作图”时使用。保留姿势与关节位置，但将整体概括为约 8.5–9.5 头身的优雅修长体块；四肢采用连续的长弧线，腰胯以流畅 S 形外轮廓衔接，肩、肘、膝、踝只用轮廓转折表达；脚概括为圆钝、无脚趾的楔形或袜模体块；手仍须保留所有可见手指与正确指序。内部线只保留肢体交叠、腋下、腹股沟和必要的手指分界，禁止肌肉线、骨骼球、关节圆和躯干分割线。

当用户提供风格图时，优先遵循风格图的线宽、体块简化和内部线密度；不得让风格图改变姿势参考中的关节位置、遮挡或左右关系。技能内置参考图位于 `assets/elongated-mannequin-lineart-reference.png`，仅在用户未提供风格图且选择“修长极简人台”时作为画风参考。

## 工作流程

### 1. 准备与查看输入

1. 明确每张输入图的唯一角色：人物照片是“精确姿势与构图参考”；线稿示例是“仅限画风参考”。同一张图可同时承担两种角色时也要分别写明哪些属性可复制。
2. 输入图只有本地路径时，先用 `view_image` 查看，再进入内置图像编辑流程。选择内置“修长极简人台”参考图时也要先查看它。
3. 默认使用内置 `imagegen`；不要为普通质量、尺寸或路径控制切换到 CLI。
4. 若没有姿势图，先把用户的姿势描述整理为头、肩、脊柱、骨盆、四肢、手足与遮挡清单；此时可以设计新姿势，但不得声称精确还原了未提供的姿势。
5. 在生成前记录不可变化项：
   - 原始宽高比与裁切；
   - 头部的偏航、俯仰和侧倾；
   - 肩线高低、躯干倾斜和重心；
   - 每条手臂、前臂、手腕的方向与遮挡；
   - 每只手可见的手指数、指序、弯曲、接触点与重叠顺序；
   - 明显的近大远小和广角夸张。

### 2. 一次生成候选成品

1. 读取 [references/prompt-recipes.md](references/prompt-recipes.md) 的“基础白模提示词”。
2. 选择“修长极简人台”时，同时加入“修长极简人台风格片段”；有风格图时使用“双参考图角色片段”。
3. 把人物照片作为唯一的姿势、构图与人体几何参考；把线稿示例或内置参考图严格限制为画风参考。
4. 在提示词中重复手部不可变化项，并明确 `do not symmetrize`。
5. 只发起一次内置 `imagegen` 调用，一次只生成一张候选成品；不主动生成多版或对比稿。

### 3. 检查并限次修复

逐项对照原图，不要只判断画面是否“好看”：

- 裁切、人物位置与原图一致；
- 头部朝向和下颌角度未被正面化；
- 肩线、躯干、肘部、手腕和前臂角度一致；
- 每根可见手指均可辨认，没有多指、少指、粘连、复制或错误遮挡；
- 手掌与脸、身体或其他手指的接触位置一致；
- 没有五官、耳朵、头发、指甲、服装、饰品或环境残留。
- 修长极简预设下，脚是简洁圆钝体块，外轮廓长弧连续，内部线数量克制，且没有关节圆、肌肉线或草稿结构线。

首图通过所有硬性门槛时立即停止生成。不因轻微线宽、不影响读姿势的小偏差或“可以更好看”而主动出新图。

只在姿势、手部、遮挡、人体完整性或禁止项明显失败时自动修复：

1. 仅选择最影响使用的一个问题，读取“单次修复提示词”。
2. 姿势、手部或遮挡错误时，从原始照片重新生成；不继续编辑错误几何，不把错误稿作为姿势参考。
3. 整个任务最多自动追加一次 `imagegen` 调用，且只生成一张修复图。修复后停止扩图；若仍未过关，交付最佳结果并说明剩余问题，等用户决定是否继续。

### 4. 保存与交付

1. 检查生成结果中的人物、背景、手部与所有禁止项。
2. 只将最终选定的一张成品复制到当前项目的 `outputs/imagegen/` 下，使用描述性文件名，例如 `chin-rest-white-model.png`。不复制或交付被淘汰的候选图。
3. 不覆盖已有文件；存在同名文件时添加 `-v2`、`-v3` 等后缀。
4. 确认文件存在、大小非零，并核对像素尺寸与格式。
5. 默认只保证原图宽高比和裁切语义，不承诺生成器保持完全相同的像素尺寸。用户要求原尺寸时，在选定成品后做确定性等比缩放或画布适配，并再次核对尺寸。
6. 最终回复中显示或链接绝对路径，说明使用了内置 `imagegen`，并概括最终提示词的关键约束。

## 硬性质量门槛

表中的失败处理共享整个任务的一次自动修复预算，不得按项目分别追加出图。

| 项目   | 通过标准                                                               | 失败处理                               |
| ------ | ---------------------------------------------------------------------- | -------------------------------------- |
| 姿势   | 构图、裁切、头部角度、肢体方向和遮挡与原图一致                         | 回到原图重生，不在错误稿上叠加修改     |
| 手部   | 可见手指数和指序正确，指间分界清晰，无增删、粘连或复制                 | 提高手部约束优先级，单独重生基础白模   |
| 白模   | 无五官、耳朵、发型、指甲、服装、饰品和明确性征                         | 做一次只删除表面特征的定向编辑         |
| 线条   | 黑线白底，无灰度、阴影、填色、排线和草稿噪点                           | 定向清理画面风格                       |
| 极简度 | 修长预设只有外轮廓、必要遮挡线和手指分界；无关节圆、肌肉线或多余躯干线 | 用风格参考重生，不在杂乱线稿上继续叠加 |

## 用户指令覆盖

- 用户说“只要外轮廓”时，删除掌纹和关节短线，只保留区分肢体与手指所需的边界。
- 用户说“保留手部细节”时，保留手指分界、关节转折、掌缘与遮挡线，但仍删除指甲。
- 用户明确要求保留五官、发型、服装或指甲时，以用户要求覆盖默认白模规范。
- 用户要求“像参考图”时，只迁移线条、比例概括、体块简化与内部线密度；除非用户同时明确要求复制姿势，否则不要把风格参考图的姿势当作目标姿势。
- 用户要求透明背景时，遵循 `imagegen` 技能的透明背景流程，不把纯白背景误当透明背景。
