# 输出契约

## 输出格式

### 1. 维度细分提示词

`方向：均以画面观察者视角为准。`

以下内容仅展示信息密度和写法，实际值必须来自参考图：

| 维度 | 细分提示词 |
|---|---|
| 1. 图像类型 | 写实摄影；竖幅 4:5；棚拍半身肖像；胸部以上景别 |
| 2. 整体风格 | 商业人像；现代编辑风格；极简视觉 |
| 3. 摄影与构图 | 平视机位；主体居中偏右；人物占画面高度约 78%；头顶留白约为头高的 5%；胸部下缘裁切；中等透视；相机与主体距离约 1.2 米 |
| 4. 主体人物 | 单人；椭圆脸；额头中等高度；颧骨平缓；下颌偏窄；眼距中等；鼻梁较直；上唇略薄于下唇 |
| 5. 身形轮廓 | 窄肩；颈部偏长；上身直立；肩线左高右低 |
| 6. 肤色与肤调 | 中等明度；暖中性肤调；脸部较颈部略亮；面颊轻微暖红 |
| 7. 动作与表情 | 头部向左转约 15°；下巴微收；双肩朝正面；直视镜头；双眼睁开；闭唇 |
| 8. 微表情 | 眉部放松；上眼睑轻压；目光集中；嘴角水平；下颌无明显紧张 |
| 9. 造型 | 黑色中长直发；中分；发尾落至锁骨；顶部低蓬松度；裸色底妆；棕灰眉；无可见首饰 |
| 10. 服装版型 | 黑色修身上衣；圆领；长袖；肩线贴合；胸腰处少量横向褶皱 |
| 11. 服装材质 | 细密针织纹理；中等厚度；低反光；柔软垂坠；不透明 |
| 12. 皮肤细节 | 面颊可见细毛孔；低磨皮；T 区小面积柔亮；眼下细纹轻微；嘴唇半哑光 |
| 13. 场景与背景 | 纯灰无缝背景纸；无前景物；主体距背景约 1.5 米；背景无明显接缝；背景亮度低于面部 |
| 14. 光线与色彩 | 主光来自左前上方约 45°；大面积柔光；右侧形成软阴影；低光比约 2:1；中性白平衡；灰黑主色；肤色与灰背景明显分离 |
| 15. 成像质感 | 焦点位于双眼；面部中高锐度；浅景深；背景散景平滑；动态范围中等；无明显运动模糊；细微单色颗粒 |
| 16. 滤镜与后期 | 整体低饱和；中低对比；黑位轻抬；高光缓和；红橙色保留；轻微暗角 |
| 17. 保真约束 | 不可水平镜像；双手不入镜；背景无文字；不增加背景物体 |

完整模式必须保留 17 行；不可判定项写 `—`。各维度按下表的“通常数量”控制信息密度；可见的重要细节不受上限限制。

### 2. 拼接后的提示词

```text
写实摄影，竖幅 4:5，棚拍半身肖像，胸部以上景别，商业人像，现代编辑风格，极简视觉，平视机位，主体居中偏右，人物占画面高度约 78%，……
```

只拼接表格中的非 `—` 片段。除分隔符和空格外，不修改内容。

## 维度取值

| 维度 | 优先覆盖 | 通常数量 |
|---|---|---|
| 图像类型 | 媒介、人像类别、方向、比例、景别 | 3–5 |
| 整体风格 | 棚拍/纪实/商业/编辑、时代感、色彩取向 | 2–4 |
| 摄影与构图 | 主体位置、占比、留白、裁切、机位、角度、距离、透视、焦点、景深 | 5–8 |
| 主体人物 | 人数、脸型、额头、颧骨、下颌、眉眼、鼻、唇、五官比例 | 5–10 |
| 身形轮廓 | 肩颈、躯干、四肢比例、重心、站坐方式、遮挡 | 3–6 |
| 肤色与肤调 | 明度、冷暖、色相、饱和度、脸颈手差异 | 3–5 |
| 动作与表情 | 头、下巴、肩、躯干、手脚、重心、视线、眼口状态 | 5–8 |
| 微表情 | 眉、眼睑、面颊、嘴角、唇部、下颌张力 | 3–6 |
| 造型 | 发色、长度、分缝、纹理、蓬松度、妆容、首饰、配件 | 4–8 |
| 服装版型 | 品类、廓形、松紧、领口、袖长、下摆、褶皱、贴合点 | 4–7 |
| 服装材质 | 织纹、厚薄、透明度、挺括或垂坠、表面反光 | 3–6 |
| 皮肤细节 | 毛孔、细纹、绒毛、妆面、磨皮、分区光泽 | 3–6 |
| 场景与背景 | 前中后景、物件、材质、空间距离、虚化、天气、文字 | 4–8 |
| 光线与色彩 | 主光方向和高度、面积、软硬、光比、阴影、色温、白平衡、主辅色 | 5–9 |
| 成像质感 | 焦点、锐度、动态范围、颗粒、噪点、散景、模糊、畸变 | 4–8 |
| 滤镜与后期 | 饱和度、对比度、黑位、高光、色彩分离、暗角、局部处理 | 4–7 |
| 保真约束 | 仅写前面未表达的防偏移约束；无新增约束时写 `—` | 0–5 |

## 语言与范围

- 默认中文；按用户要求切换语言或输出双语。
- 定向提取只保留用户指定的维度，并只拼接这些维度。
- 不输出身份或敏感属性推断。
- 不输出无证据的品牌、器材、摄影师、艺术家、胶片或滤镜名称。
- 用户没有明确要求时，不附加分析、负面词或参数。
